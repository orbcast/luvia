# Luvia Rules

Luvia 是一个视频播放器。`luvia-rules` 用于维护播放器使用的源规则和资源源，描述资源从哪里来，以及如何按规则发现、解析或接入这些资源。这里的“源”指内容或资源的来源，不是播放器应用的源代码。

当前目录先确立用途与维护边界，尚未定义规则格式、源清单或加载协议，也未实现与播放器的接入。新增具体规则时，应同时说明对应资源源、规则格式、适用范围、使用方式与验证方法，不把规划写成已实现能力。

## 维护边界

本目录承载源规则、资源源相关配置及必要说明，不承载播放器 UI、播放引擎或其他应用内部业务。规则按实际来源与职责组织，不预建无需求的解析框架。需要校验工具时，将其依赖与运行方式记录在本目录，避免依赖其他应用的内部实现或本机绝对路径。

规则行为应有可重复的验证；涉及解析与匹配时优先使用本地样例覆盖正常、无效与边界输入，不以真实网络资源是否在线作为唯一证据。规则或配置变化不默认触发播放器的完整 UI 测试，只有影响播放器接入行为时才增加对应验证。

## 随时可能迁移到独立仓库

`luvia-rules` 目前暂放在当前仓库的 `apps/` 下，**未来随时可能从当前仓库迁移到一个独立仓库维护与发布**。当前位置不代表它是可运行的应用，也不意味着它必须长期随播放器主仓库维护。

新增内容时保持目录自包含：使用目录内的相对引用，记录规则与资源的来源、必要的授权信息、格式和使用说明，明确工具依赖；不要依赖 `apps/desktop` 的内部类型、构建产物或仓库根目录的隐式行为。播放器与规则源之间需要接入时，通过明确的文件格式或加载契约连接，使迁移后可以调整来源地址而无需复制播放器内部实现。

实际拆仓时需同步消费者引用与获取方式，并维护格式兼容性；当前仅记录迁移预期，不创建独立仓库、不配置远程地址，也不提前设计发布系统。
