# UI 术语

统一使用以下中英文名称；新增术语与用户确认，更名时同步相关引用。

| 英文 / 中文 | 定义 |
| --- | --- |
| AppShell / 应用Tabbar | desktop 主窗口左侧的一级导航区域，包含发现、资源库、追剧、搜索、设置，不含窗口顶栏、系统菜单和业务内容区。 |
| Resource Library / 资源库 | desktop 的内容页之一，按内容类型分类浏览数据源列表：顶部分类页签与搜索、筛选行、海报网格/列表；只读源列表与本地追剧集合，不含播放与详情。 |
| Category tab / 分类页签 | 资源库顶部的六个彩色圆角块（全部、电影、剧集、动漫、综艺、短剧），选中项带蓝色描边环；切换即按类型重新请求列表。 |
| Source / 数据源 | `apps/luvia-rules/<source-id>/` 中的一个源，由一条规则描述，实现首页、列表、详情、选集、解析中的若干操作；同一源的播放线路不拆成多个源。 |
| Title page / 详情页 | desktop 的内容页之一，由来源的详情与选集数据构成：海报卡、标签、标题、指标芯片、简介、追剧与选集网格，以及右栏收藏、资料与标签；从发现页或资源库进入，返回上一层。 |
| Player / 播放页 | desktop 的播放屏，解析来源线路后用系统视频组件播放，画面叠加控制条；打开时默认收起右侧面板，画面占满窗口，由画面右上角的展开按钮唤出正在播放、简介、播放源切换与选集；关闭回到详情页。 |
